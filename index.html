Frequently Asked Questions

How does the random selection tool work?

The tool reads each non-empty line as an individual option and uses the browser's Web Crypto random number generator to select entries. Results are generated locally in your browser.

Can I select multiple random names at once?

Yes. Enter your list, set Quantity to Pick to the number of names you need, and trigger random selection. The unique selection mode prevents the same input entry from being selected twice.

Can I use this tool to pick giveaway winners?

Yes. Add eligible participant names or entry IDs, choose the number of winners and generate a selection. For important or regulated promotions, establish and publish fair eligibility and selection rules before running the draw.

Does the randomizer allow duplicate results?

Yes. Choose Allow repeated results to let an input item appear more than once. Choose No repeated results when each selected entry must be unique.

Are my input items uploaded to a server?

The selection logic in this page runs in your browser. The randomization code does not send your entered list to a server. Avoid entering confidential information into any website unless you have reviewed its privacy practices.

Can I download my random results?

Yes. After generating results, use the Download TXT button to save a plain-text file containing your selected entries.
